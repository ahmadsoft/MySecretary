# سكرتيري (MySecretary)

تطبيق Flutter لنظامي **Android و iOS** لتنظيم المهام اليومية، بواجهة عربية كاملة (من اليمين لليسار).
جميع البيانات محفوظة محلياً على الجهاز (SQLite).

## التصميم
- **بطابع iOS**: أقسام مجمّعة بزوايا دائرية مثل إعدادات iPhone، وعناوين كبيرة، وشريط تبويب iOS، ومفاتيح تبديل وأدوات تحديد مقسّمة، وعجلات اختيار التاريخ، ونوافذ تأكيد iOS، والسحب للرجوع.
- **تصميم زجاجي**: شريط تبويب عائم بشكل كبسولة زجاجية شفافة، وبطاقات بزوايا دائرية كبيرة وظلال خفيفة وتعتيم ضبابي فوق خلفية ملونة ناعمة.
- **أيقونات Cupertino** (أيقونات iOS) في كامل التطبيق، مع ألوان نظام iOS الرسمية.
- **الخط**: على iPhone يُستخدم خط النظام نفسه (SF Pro / SF Arabic). أما على أندرويد فيُستخدم Inter للأرقام والحروف اللاتينية و IBM Plex Sans Arabic للعربية، وهما أقرب خطين مجانيين لخط iPhone، لأن ترخيص Apple لا يسمح بتضمين خط SF في تطبيقات أندرويد. تراخيص الخطين (SIL OFL) موجودة في `assets/fonts/`.

## المزايا

### المرحلة الأولى
- **لوحة اليوم**: تحية، نسبة إنجاز مهام اليوم، المواعيد، المهام المتأخرة، مصروف اليوم والشهر، واختصارات سريعة.
- **المهام**: أولوية (منخفضة/متوسطة/عالية)، تصنيفات، موعد استحقاق، تذكير، تكرار (يومي/أسبوعي/شهري) ينشئ المهمة التالية تلقائياً عند الإنجاز، مهام فرعية، بحث، وحذف بالسحب.
- **التقويم والمواعيد**: عرض شهري، أسبوعان، أسبوع. للموعد مكان ولون وتذكير قبل الموعد بمدة تختارها.
- **الملاحظات**: ملونة، قابلة للتثبيت، مع بحث وحفظ تلقائي.
- **الإشعارات المحلية**: تعمل بدون إنترنت.
- **الوضع الليلي والنهاري**.

### المنبه بملء الشاشة (الإعدادات ← التنبيهات)
- تذكيرات المهام والمواعيد تظهر **بملء الشاشة مثل منبه الجهاز**: الوقت بخط كبير، عنوان التذكير، صوت منبه متكرر واهتزاز.
- زرّا **إيقاف** و**تأجيل 10 دقائق** (في الشاشة وعلى الإشعار نفسه، حتى والجوال مقفل).
- **أندرويد**: يظهر فوق شاشة القفل ويُشغّل الشاشة، ويرن بصوت المنبه حتى الإيقاف أو التأجيل (يتوقف تلقائياً بعد 10 دقائق).
- **iPhone**: لا يسمح النظام للتطبيقات بفتح شاشة كاملة فوق شاشة القفل، لذا يظهر إشعار "حساس للوقت" فيه زرّا الإيقاف والتأجيل، وعند الضغط عليه أو إذا كان التطبيق مفتوحاً تظهر شاشة المنبه الكاملة بالصوت.
- يمكن إيقاف الوضع والعودة للإشعارات العادية، مع زر لتجربة المنبه.

### المرحلة الثانية
- **إدارة المصاريف**
  - تسجيل يدوي للمصروفات والإيرادات، مع طريقة الدفع والجهة.
  - **قراءة رسائل البنوك تلقائياً (Android)**: عند وصول رسالة يُستخرج المبلغ ونوع العملية (شراء/سحب/إيداع/حوالة) والتاجر، وتُسجل العملية ويصلك إشعار بذلك. يعمل هذا والتطبيق مغلق أيضاً، وعند أول تفعيل تُستورد رسائل آخر 30 يوماً.
  - تُتجاهل رسائل رموز التحقق والعمليات المرفوضة، ولا تُسجل الرسالة الواحدة مرتين.
  - إمكانية حصر القراءة على مرسلين محددين (أسماء البنوك).
  - **تصنيف تلقائي**: عبر كلمات مفتاحية (مطاعم، بقالة، وقود…)، ويتعلم التطبيق من تصحيحاتك فيصنّف نفس التاجر تلقائياً في المرات القادمة.
  - **لصق رسالة بنك**: خيار لنظام iOS الذي لا يسمح بقراءة الرسائل.
  - ملخص شهري، ورسم دائري لتوزيع المصروفات، وميزانية شهرية لكل تصنيف مع تنبيه عند تجاوزها.
- **حسابات الورثة**
  - عدة حسابات تركات.
  - الورثة ونصيب كل وارث، ويُدخل النصيب كنسبة (12.5) أو ككسر (1/8)، مع تنبيه إذا لم يكن مجموع الأنصبة 100%.
  - **مصادر الإيراد**، مثل إيجار عمارة أو بيع أصل أو أرباح، ويُربط كل إيراد بمصدره.
  - مصروفات التركة حسب البند (صيانة، رسوم، زكاة، سداد دين…).
  - تسجيل الصرف لكل وارث.
  - ملخص يعرض الإيرادات حسب المصدر والمصروفات حسب البند وصافي التركة والرصيد المتبقي، ولكل وارث: المستحق والمصروف له والمتبقي.
  - كشف حساب لكل وارث، ونسخ تقرير نصي كامل لمشاركته عبر واتساب.

### النسخ الاحتياطي (المزيد ← النسخ الاحتياطي)
- **نسخة كاملة** لجميع البيانات (المهام، المواعيد، الملاحظات، المصاريف، التصنيفات، حسابات الورثة والإعدادات) في ملف JSON واحد.
- **حفظ في الملفات** (iCloud Drive أو الجهاز)، أو **مشاركة** عبر AirDrop/واتساب/البريد.
- **استعادة من ملف**: يعرض ملخص النسخة قبل الاستعادة، ويستبدل البيانات الحالية بالكامل ويعيد جدولة التذكيرات.
- **تصدير CSV** للعمليات المالية وحركات حسابات الورثة، يفتح في Excel و Numbers و Google Sheets.

## التشغيل

```bash
flutter pub get
flutter run            # على جهاز أو محاكي
flutter test           # الاختبارات
flutter build apk      # نسخة أندرويد
flutter build ios      # نسخة iOS (تحتاج جهاز Mac مع Xcode)
```

## ملاحظات مهمة
- **iOS لا يسمح بقراءة الرسائل النصية** لأي تطبيق، لذلك تتوفر عليه ميزة "لصق رسالة بنك" فقط.
- **متجر Google Play** يقيّد إذن قراءة الرسائل (READ_SMS) ويقصره عادةً على تطبيقات الرسائل الافتراضية. للاستخدام الشخصي ثبّت ملف APK مباشرة. أما النشر في المتجر فيتطلب نموذج استثناء من Google أو إزالة هذه الميزة.
- محلل الرسائل (`lib/services/sms_parser.dart`) مجرّب على صيغ شائعة لرسائل البنوك بالعربية والإنجليزية. إذا لم تُقرأ رسالة من بنكك جرّبها من "رسائل البنوك ← تجربة قراءة رسالة"، وأرسل لي نصها (بعد إخفاء الأرقام الحساسة) لأضيف دعمها.

